# Flashcard Quiz App

A feature-rich flashcard quiz application built with **Flutter** and **Dart** as part of the **CodeAlpha App Development Internship**. The app helps users study any topic by creating custom flashcards with questions and answers, navigating through them, and testing their knowledge on the go.

## Features

**Core Functionality**
- Interactive flashcards with question on the front and answer on the back
- Smooth "Show Answer" / "Hide Answer" toggle
- Navigate between cards using Next and Previous buttons
- Full CRUD support: Add, Edit, and Delete flashcards

**User Experience**
- Progress bar showing current card position out of total cards
- Card counter displaying which card you're viewing
- Animated card transitions for a polished feel
- Color coded cards: white for questions, purple for answers
- Tap anywhere on the card to flip it

**Design**
- Built with Material Design 3 (Material You)
- Clean, minimal, and intuitive interface
- Responsive layout that works across all screen sizes
- Custom purple color theme throughout the app

## Tech Stack

- **Framework:** Flutter 3.47.5
- **Language:** Dart
- **UI:** Material Design 3
- **State Management:** setState
- **Architecture:** Single page application with dialog based CRUD

## How It Works

1. Launch the app to see the first flashcard with a question
2. Tap "Show Answer" or tap the card to reveal the answer
3. Use Next/Previous buttons to navigate between cards
4. Tap the + button to add your own custom flashcards
5. Use the pencil icon to edit the current card
6. Use the trash icon to delete a card you no longer need

## Getting Started

1. Clone the repository
```
git clone https://github.com/Syed-Khizer-Rizvi/CodeAlpha_Flashcard_Quiz_App.git
```
2. Navigate to the project
```
cd CodeAlpha_Flashcard_Quiz_App
```
3. Install dependencies
```
flutter pub get
```
4. Run the app
```
flutter run
```
